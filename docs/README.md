# Documentación

Este directorio recoge las especificaciones del producto y las decisiones de arquitectura del sitio.

## Convención

- Las especificaciones viven en `docs/specs/NNN-nombre.md` (ejemplo: `docs/specs/001-sitio-hugo-minimo.md`).
- Las decisiones de arquitectura (ADR) viven en `docs/adr/NNN-nombre.md` (ejemplo: `docs/adr/001-stack-e-infraestructura-aws.md`).
- `NNN` es un número correlativo de tres dígitos. El nombre va en minúsculas y con guiones.

## Aprobación

Ninguna spec pasa a desarrollo sin la aprobación explícita de Jorge (Product Owner). Esa aprobación se da al revisar y fusionar el pull request de la spec.
